# VR6 Eurovan (12‑Valve) Manual Transmission Swap — DIY Overview

This document provides a high‑level, step‑by‑step outline for converting a 1997 VR6 Eurovan/Winnebago Camper from the 01P automatic to the 02G manual transmission.

---

## 1. Preparation

- Disconnect battery.
- Raise and support the van securely.
- Remove undertray and components blocking access.
- Support engine with an engine support bar or jack under the oil pan.

---

## 2. Remove the 01P Automatic Transmission

1. Drain ATF and disconnect cooler lines.
2. Remove axles from transmission.
3. Disconnect shifter cable(s) and range selector wiring.
4. Unplug transmission harness; leave TCM in place for now.
5. Remove starter and torque converter bolts.
6. Support transmission with a jack.
7. Remove bellhousing bolts and transmission mounts.
8. Lower and remove the 01P.

---

## 3. Install Pedal Cluster and Clutch Hydraulics

1. Remove lower dash trim and knee bolster.
2. Remove automatic pedal assembly.
3. Install manual pedal cluster and clutch pedal hardware.
4. Install clutch master cylinder through firewall.
5. Route hydraulic line to slave cylinder location.
6. Tee into brake reservoir or install dedicated reservoir.

---

## 4. Flywheel, Clutch, and Rear Main Seal

1. Remove flexplate from VR6 crankshaft.
2. Inspect or replace rear main seal.
3. Install manual flywheel with new bolts (torque to spec).
4. Install clutch disc and pressure plate using alignment tool.

---

## 5. Prepare and Install the 02G Manual Transmission

1. Replace input shaft and axle seals if needed.
2. Install slave cylinder on transmission.
3. Mate transmission to engine and install bellhousing bolts.
4. Install manual transmission mounts and brackets.

---

## 6. Axles and Shifter Installation

1. Install axles or inner CV cups; torque hardware to spec.
2. Install shifter box inside cabin.
3. Route and connect shift cables/rods.
4. Adjust shifter alignment per donor procedure.

---

## 7. Hydraulics and Wiring

1. Connect clutch hydraulic line to slave cylinder.
2. Bleed clutch system until engagement is firm.
3. Wire reverse‑light switch to original circuit.
4. Install TCM emulator into TCM harness.

---

## 8. Final Steps and First Drive

1. Fill transmission with correct gear oil.
2. Reconnect battery.
3. Verify no warning lights (TCM emulator should prevent CEL).
4. Test clutch engagement.
5. Perform low‑speed test drive:
   - Check all gears
   - Listen for vibration or grinding
6. Re‑torque axle and mount hardware after first drive.

---

## Notes

- This is a bolt‑in swap; no fabrication is required.
- The TCM emulator is essential for VR6 manual conversions.
- Replace seals and bushings while accessible for long‑term reliability.
