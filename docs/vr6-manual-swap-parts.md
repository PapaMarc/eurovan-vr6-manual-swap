# VR6 Eurovan (12‑Valve) Manual Transmission Swap — Parts List

This document lists all components required to convert a 1997 VR6 Eurovan/Winnebago Camper from the 01P automatic to the 02G manual transmission.

---

## 1. Core Drivetrain Components

- **02G 5‑speed manual transmission**
  - VR6‑specific bellhousing
  - Selector tower
  - Reverse‑light switch
  - Speed sensor (if included)

- **Flywheel (manual VR6)**
  - Single‑mass preferred
  - New flywheel bolts

- **Clutch kit**
  - Pressure plate
  - Clutch disc
  - Release bearing
  - Pressure plate bolts

- **Starter (manual‑transmission VR6)**

- **Axles / Inner CVs**
  - Manual‑specific axles, or
  - Existing axles with manual inner CV cups
  - New CV boots/grease (recommended)

- **Transmission mounts**
  - Left and right manual‑specific brackets
  - Mount hardware

---

## 2. Pedals, Hydraulics, and Shifter

- **Manual pedal cluster**
  - Clutch pedal
  - Narrow brake pedal
  - Pedal bushings and return spring

- **Clutch hydraulics**
  - Clutch master cylinder
  - Clutch slave cylinder (02G)
  - Hard line or braided line
  - Reservoir tee or dedicated reservoir

- **Shifter assembly**
  - Floor shifter box
  - Shift lever, boot, trim
  - Shift cables/rods (depending on donor)
  - Bushings, clips, cable ends

---

## 3. Electronics and Wiring

- **TCM emulator**
  - Plug‑and‑play 01P transmission emulator for VR6 Eurovan

- **Wiring**
  - Reverse‑light switch pigtail
  - Connectors, heat‑shrink, wire for:
    - Reverse lights
    - Optional clutch‑switch integration

---

## 4. Consumables and Hardware

- **Fluids**
  - GL‑4 gear oil (per 02G spec)
  - DOT 4 brake fluid (clutch system)

- **Seals**
  - Transmission input shaft seal
  - Axle flange seals
  - VR6 rear main seal (recommended)

- **Miscellaneous**
  - Penetrating oil
  - Assembly lube
  - Assorted M8/M10 hardware
  - Zip ties, brackets, clamps

---

## 5. Optional / Recommended Upgrades

- Single‑mass flywheel conversion (if not already SMF)
- New engine mounts
- New shifter bushings
- Stainless clutch line
- New pedal bushings
